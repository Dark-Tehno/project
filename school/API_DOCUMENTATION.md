# API школьного проекта по русскому языку

API помогает готовиться к заданиям ЕГЭ по русскому языку: расстановке ударений (задание 4) и паронимам (задание 5).

Тесты по умолчанию составляются из проверенного банка (`bank.py`) — это быстро, бесплатно и без ошибок в ответах. GigaChat подключается по желанию: для генерации новых заданий (`?source=ai`) и для подробного разбора ответов (`POST`).

## Общие сведения

- Базовый путь: `/school/api/`
- Формат тела запроса: JSON (`Content-Type: application/json`)
- Пути включают завершающий `/`.
- Нужен аутентифицированный пользователь Django REST Framework (сессия или другая настроенная аутентификация). Без входа — `401`/`403`.
- Ограничение частоты: 60 запросов в минуту на пользователя (`429` при превышении).
- Успешные запросы возвращают JSON.

## Настройка GigaChat

Ключ больше **не хранится в коде**. Задайте его в `settings.py` или переменной окружения:

| Параметр | Назначение | По умолчанию |
|---|---|---|
| `GIGACHAT_CREDENTIALS` | ключ авторизации (обязателен для ИИ) | — |
| `GIGACHAT_MODEL` | модель | `GigaChat-3-Ultra` |
| `GIGACHAT_SCOPE` | scope | `GIGACHAT_API_PERS` |
| `GIGACHAT_BASE_URL` | адрес API | `https://api.giga.chat/v1` |
| `GIGACHAT_VERIFY_SSL` | проверять TLS-сертификат (`1`/`0`) | `0` |

Без `GIGACHAT_CREDENTIALS` тесты из банка работают, а ИИ-запросы вернут `503`.

## Ударения

### `GET /school/api/stress-marks/`

Тест из пяти слов: 2–3 слова показаны с ошибкой в ударении.

Параметр `source`: `bank` (по умолчанию) или `ai`. Если ИИ не смог составить корректный тест (проверяется формат ответа), возвращается тест из банка с `"fallback": true`.

**Ответ — `200 OK`:**

```json
{
  "test": "1. туфлЯ | + | Верно: туфлЯ (ударение на 2-м слоге).\n2. ...",
  "task": "Укажите варианты ответов, в которых верно выделена буква, обозначающая ударный гласный звук.",
  "items": [
    {"shown": "тОрты", "right": "тортЫ", "correct": false,
     "explanation": "Ошибка. Правильно: тортЫ (ударение на 2-м слоге). ..."}
  ],
  "source": "bank"
}
```

- `items[].shown` — вариант, который видит ученик (заглавная — ударная гласная);
- `items[].right` — нормативный вариант;
- `items[].correct` — верно ли ударение в `shown`;
- `test` — то же в текстовом виде (формат прежней версии API: `N. слово | +/- | пояснение`).

### `POST /school/api/stress-marks/`

Разбор слов от ИИ.

```json
{"words": ["туфлЯ", "понЯв", "дОнельзя", "корЫсть", "Оптовый"]}
```

`words` — список из 1–10 строк (до 60 символов), заглавная буква — ударная.

**Ответ — `200 OK`:** `{"result": "Разбор от ИИ..."}`

## Паронимы

### `GET /school/api/paronyms/`

Пять предложений, в одном из которых вместо нужного слова употреблён его пароним. Параметр `source` — как выше.

**Ответ — `200 OK`:**

```json
{
  "test": "Текст задания\n\n1. ... | + | ...",
  "task": "В одном из приведённых ниже предложений НЕВЕРНО употреблено выделенное слово. ...",
  "items": [
    {"text": "Налог необходимо ОПЛАТИТЬ до конца месяца.", "correct": false,
     "answer": "уплатить", "explanation": "Слово употреблено неверно, нужен пароним «уплатить». ..."},
    {"text": "Студенту ПРЕДОСТАВИЛИ академический отпуск.", "correct": true,
     "answer": "", "explanation": "Слово употреблено верно. ..."}
  ],
  "source": "bank"
}
```

`answer` заполнен только у ошибочного предложения (ровно одно на задание).

### `POST /school/api/paronyms/`

```json
{"sentences": ["Не так легко было найти выход из ЗАТРУДНЁННОГО положения.", "В ИГОРНОМ зале казино было много людей."]}
```

`sentences` — список из 1–10 строк (до 400 символов), выделенное слово — заглавными. **Ответ:** `{"result": "..."}`.

## Ошибки

| Код | Когда | Тело |
|---|---|---|
| `400` | нет `words` / `sentences`, неверный формат или слишком длинные значения | `{"error": "No words provided"}` / `{"error": "No sentences provided"}` |
| `401`/`403` | не выполнен вход | стандартный ответ DRF |
| `429` | превышен лимит запросов | стандартный ответ DRF |
| `502` | ошибка при обращении к GigaChat | `{"error": "ИИ сейчас недоступен. Попробуйте позже."}` |
| `503` | не задан `GIGACHAT_CREDENTIALS` | `{"error": "GigaChat не настроен: ..."}` |

## Структура и тесты

- `bank.py` — банк слов с ударениями (75) и паронимов (29); расширяется добавлением строк;
- `generators.py` — сборка тестов, проверка ответов ИИ, промпты (без зависимости от Django);
- `views.py` — эндпоинты;
- `test_generators.py` — тесты: `python manage.py test school` или `python -m unittest school.test_generators` из корня проекта.
